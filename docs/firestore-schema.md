# Cloud Firestore Database Design & Schemas

Platform: **Adaptive Interview Intelligence**  
Database: **Google Cloud Firestore (Native Mode)**

---

## 1. Overview of Collections

The database consists of 10 persistent top-level collections with clear document relationships, role-based ownership, and audit timestamps.

```
├── users/                     # Candidate & Recruiter user accounts
├── jobs/                      # Job postings with required skills & criteria
├── applications/              # Candidate applications for jobs
├── interviews/                # State-controlled interview sessions
├── interview_questions/       # Adaptive interview questions
├── interview_answers/         # Candidate answers submitted
├── skill_evaluations/         # AI-generated answer evaluations & scores
├── integrity_events/          # Proctoring anomalies & integrity audit trail
├── skill_gap_reports/         # Skill deficit & readiness analysis
└── interview_reports/         # Comprehensive hiring evaluation reports
```

- **Purpose**: Stores profile details and trusted role identity.

## 3. Recommended Firestore Composite Indexes

For high-volume production query performance:

| Collection | Fields | Query Type |
|---|---|---|
| `jobs` | `status` (ASC), `createdAt` (DESC) | Candidate job discovery |
| `jobs` | `recruiterId` (ASC), `status` (ASC), `createdAt` (DESC) | Recruiter job management |
| `applications` | `jobId` (ASC), `createdAt` (DESC) | Recruiter application inbox |
| `interviews` | `candidateId` (ASC), `status` (ASC), `createdAt` (DESC) | Candidate session list |
| `interviews` | `recruiterId` (ASC), `status` (ASC), `createdAt` (DESC) | Recruiter session list |
| `interview_questions` | `interviewId` (ASC), `questionIndex` (ASC) | Sequential interview flow |
| `interview_reports` | `jobId` (ASC), `overallScore` (DESC) | Recruiter candidate ranking |
